# Catálogo Digital — Feira do Total Ville

Projeto demonstrativo de catálogo digital responsivo para apresentar categorias e atrações da feira de sexta-feira do Setor Total Ville, em Santa Maria – DF.

## Funcionalidades
- Layout responsivo para celular e computador.
- Filtros por Gastronomia, Variedades e Artesanato, e Lazer e Família.
- Campo de busca por produtos e atividades.
- Seção sobre sustentabilidade e valorização do comércio local.
- Desenvolvido com HTML, CSS e JavaScript puro.

## Como visualizar
1. Baixe ou clone este repositório.
2. Abra a pasta do projeto.
3. Abra o arquivo `index.html` no navegador.

## Como publicar no GitHub Pages
1. Crie um repositório no GitHub.
2. Envie os arquivos `index.html`, `style.css`, `script.js` e `README.md` para a raiz do repositório.
3. Acesse **Settings → Pages**.
4. Em **Build and deployment**, selecione **Deploy from a branch**.
5. Escolha a branch `main` e a pasta `/ (root)`, depois clique em **Save**.
6. Aguarde a publicação e acesse o endereço gerado pelo GitHub Pages.

## Personalização
Edite os cards diretamente no `index.html`. Cada card tem:
- `data-category`: `gastronomia`, `variedades` ou `lazer`.
- `data-search`: palavras que ajudam a busca a encontrar o item.
- Título e descrição apresentados ao visitante.

Os itens e textos atuais são ilustrativos. Antes de usar como catálogo oficial, confirme com os comerciantes os produtos, preços, contatos, horários e atrações disponíveis. Você também pode substituir os emojis por fotos reais autorizadas.

## Relação com o projeto de extensão
A proposta utiliza uma ferramenta digital simples para ampliar a divulgação dos pequenos comerciantes, facilitar o acesso às informações da feira e permitir destaque para ofertas do dia, contribuindo para a valorização do comércio local e para a redução de possíveis desperdícios.
